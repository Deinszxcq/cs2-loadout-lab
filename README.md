# Loadout Lab
Prototipo estático personal de equipamiento CS2. Abrir mediante servidor HTTP en dist/.
Guarda selecciones y conjuntos en localStorage del navegador. No sincroniza con Steam.
Catálogo de prueba: 8 armas, 12 acabados por arma. Agentes e imágenes: Valve, catálogo de ByMykel/CSGO-API (https://github.com/ByMykel/CSGO-API).
